# Simply E-Commerce - Seller Dashboard (PWA / Web)

This package represents the merchant dashboard application.

## Key Architectural Principles
- **Installed PWA**: Offline caching, camera barcode scanning, push notifications.
- **OTP-First Authentication**: Indian phone number verification via OTP.
- **Persistent Secure Sessions**: Rotating refresh tokens, device management, instant remote logout.
- **Private Store Preview**: Ability to preview catalogue, variants, and branding even when subscription is unpaid.
- **Catalogue & Inventory Management**: Multi-variant matrix, colour images, SKU tracking, stock movements.
- **Order Processing & Fulfillment**: Razorpay status tracking, Shiprocket manifest generation.
