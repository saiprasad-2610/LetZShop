# Simply E-Commerce - Platform Admin Application

This package represents the super-admin platform console.

## Key Capabilities
- **Tenant Management**: Monitor merchants, businesses, and stores.
- **Subscription Administration**: Override plan limits, extend trials, review payment invoices.
- **Store Status Controls**: Suspend abusive stores, audit manual overrides.
- **Privacy & DPDPA Governance**: Review and fulfill customer data export and erasure requests.
- **System Telemetry & Audit Logs**: Trace security events, integration failure retries, and outbox queues.
